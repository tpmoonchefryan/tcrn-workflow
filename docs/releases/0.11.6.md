# TCRN Workflow 0.11.6

`0.11.6` is the INIT-020 migration-resume patch release.

## The change

- A migration target that is a strict, byte-identical prefix of the source is
  now resumed as designed; only divergent, advanced, or same-version targets
  are refused as `WORKSPACE_MIGRATION_FUTURE`.
- Added a regression test for a segment-level interruption and resume.

## Compatibility

- No CLI shape or event schema changes.
- The release keeps the storage-home sentinel and full migration read-back
  requirements unchanged.
- The release is local-only until the Owner clears the push/privacy gate.
