# TCRN Workflow 0.11.8

`0.11.8` is the INIT-020 hardening release candidate carrying the Story-209 and
public-preflight contract updates.

It closes the migration and storage-home admission gaps, carries storage authority
identity through sealed read status, requires the named Postgres append-only trigger,
and rejects epoch lease fallbacks. The test-wiring and ADR gates now validate their
structured negative legs, and `release:preflight` binds a green P8 result to the
exact candidate tag commit while refusing source-code changes in a release commit.

The work status graph also includes the non-terminal
`pending-owner-acceptance` state. Implementations can leave a completed item
awaiting Owner judgment without falsely marking it `done`; an Owner can return
it to `active` or accept it to `done`.

Story scopes now require the exact ten blocks `Goal`, `Requirements`, `Acceptance
Criteria`, `Business Background`, `Preconditions`, `Assumptions`, `Use Cases &
Examples`, `Feature Toggle & Setting`, `Permissions`, and `Implementation Notes`.
Dispatch briefs, closeout verification, source-to-rule conservation, and the
independent public-world preflight are executable gates with negative legs.
The generated verification map and RC1 proof manifest are refreshed from the
same final source basis and are checked for byte-current parity.

The release bytes are ready for the separately authorized tag and publication
operation; no AOS compatibility pair is claimed.

## STORY-209 scope-contract compatibility note

This candidate adds an additive Story scope path (`--scope` and `--decided-by`)
and makes the scope mandatory for new Stories. Existing terminal records remain
read-only history; non-terminal Stories are migrated by append-only
`work-annotate` plus live readback. Readers and writers of a chain that uses the
annotation must use a compatible Workflow build. See
`docs/compatibility/story-209-scope-contract.md`; no AOS compatibility pair,
tag, or publication is claimed here.
