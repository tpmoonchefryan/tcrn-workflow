# TCRN Workflow 0.11.5

`0.11.5` is the INIT-020 migration-equivalence patch release.

## The change

- `migration-verify` compares the four workspace views by canonical view name
  and bytes, independent of FileBackend versus PostgreSQL enumeration collation.
- The regression test exercises the mixed-case `STATUS.md` view alongside the
  three JSON views.

## Compatibility

- No CLI shape or event schema changes.
- Existing file and Postgres chains remain byte-equivalent; only a false
  collation-based migration red is removed.
- The release is local-only until the Owner clears the push/privacy gate.
