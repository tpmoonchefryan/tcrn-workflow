# TCRN Workflow 1.1.2

This append-only patch release preserves the v1.1.1 event, storage, and CLI
protocols.

## Repairs

- Helper deployment freshness now accepts only the closed pin grammar used by
  the supported payloads: `Supports TCRN Workflow`, `Targets TCRN Workflow`,
  or `Targets the TCRN Workflow`, each with one exact non-empty version.
  Missing, malformed, and conflicting pins remain red.
- Platform doctor derives its host-render comparison root from the managed
  Engine checkout declared by `machine.workflow-engine`. The development
  checkout is no longer an implicit fallback.
- The proof-surface repair is included in the final candidate lineage; all
  release identities and generated assets are measured from that exact tree.

The immutable v1.1.1 Engine and v1.0.3 Helper publications remain unchanged.
This release is published only after exact-commit CI succeeds and its tags,
assets, bootstrap, and downloaded digests are independently verified.
