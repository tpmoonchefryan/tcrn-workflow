# TCRN Workflow 0.11.7

`0.11.7` is the INIT-020 fork-recovery patch release.

It adds two engine verbs for the storage-home control plane:

- `storage-home-seal` validates the live PG-backed workspace at an expected
  version, then writes an immutable PG storage-home declaration to the retained
  file archive. It never copies or overwrites archive events, so a divergent
  archive remains available for INC-083/INC-081 forensics.
- `storage-home-status` reads the declaration through the engine for a named
  read-back.

The seal is fail-closed on an absent PG connection, a schema mismatch, a stale
expected version, an invalid PG chain, and a conflicting existing declaration.
An identical binding is idempotent and preserves its original migration instant.

The release supersedes the 0.11.6 deployment for this control-plane operation;
the earlier migration-equivalence and prefix-resume fixes remain included.
