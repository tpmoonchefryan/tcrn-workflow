# TCRN Workflow 0.10.1

`0.10.1` is a patch release that corrects **WSA-3** (closing an Initiative with
live non-terminal work). `0.10.0` placed the check in the work-graph validator,
which a replay runs over every historical event; an existing chain that had
prematurely closed an Initiative before `0.10.0` therefore failed replay and
became unreadable. `0.10.1` moves the check to the **write path**, so history
stays readable and the rule still holds for new closes.

## The change

- **Before (0.10.0, defective):** WSA-3 in `validateWorkGraph`. A replay of a
  chain containing a done Initiative whose descendants were open at some point
  failed with `WORKSPACE_EVENT_CORRUPT`, making the whole chain unreadable.
- **After (0.10.1):** WSA-3 in `transitionWork`, as write-path admission. Moving
  an `Initiative` to `done` when its subtree holds live non-terminal work is
  refused with `WORKSPACE_INPUT_INVALID`. Replay does not run this check.

## Compatibility

- No verb, event-schema, or storage-version change.
- `PROTOCOL_REASON_CODES` returns to the 0.9.0 set (the 0.10.0-only
  `WORK_GRAPH_ACTIVE_CHILDREN_OF_DONE_INITIATIVE` is removed; the core layer
  reports `WORKSPACE_INPUT_INVALID`).
- Chains are byte-identical across 0.9.0 / 0.10.0 / 0.10.1 — this patch changes
  validation placement, not event bytes.
