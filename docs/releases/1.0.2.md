# TCRN Workflow 1.0.2

This is an immutable unpublished local candidate for the INIT-051 repair set.
It has no supported AOS release and performs no publication or deployment.

## Included repairs

- The telemetry coverage reader pairs repeated `start`/`stop` intervals from
  one trusted session and still rejects gaps, phase errors, sequence errors,
  incompatible sources, and bad high-water evidence.
- The portal no longer publishes the retired identity vocabulary or an empty
  effort category, and manual article composition is replaced by governed
  knowledge listing, search, source references, and body reads.
- The helper candidate verifies the fixed companion digest before invoking the
  disposable test-root checker and rejects missing, altered, and replaced
  companion files before any install state is written.

The candidate remains separate from the external bootstrap trust anchor,
annotated tag, publication, live host installation, and Owner visual acceptance.
