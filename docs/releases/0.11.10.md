# TCRN Workflow 0.11.10

`0.11.10` is the INIT-023 productization release candidate. It makes a machine
level engine safe to run against many governed workspaces, and it finishes the
settings surface so a consumer can offer the values the engine will actually
accept.

A workspace can now declare the engine version it requires, and an engine that
does not satisfy that declaration refuses by name. Before this, an engine older
than the contract a chain was written under surfaced as a corrupt-chain result:
a version problem wearing the costume of data damage, which cost one incident
and an escalation. The refusal now carries both version numbers, so the reader
is told what to do rather than what broke. A workspace that carries no
declaration reads and writes exactly as before.

The settings catalog also publishes the closed set of values an enum key
accepts, and a refused write names them. A consumer building a selector no
longer has to hard-code a second copy of the enum and hope it stays in step
with the engine, and a person whose write was refused is told which values
would have been accepted.

The release bytes are ready for the separately authorized tag and publication
operation; no AOS compatibility pair is claimed.

## Compatibility note

Both surfaces are additive. A chain written by an earlier build reads
unchanged, a workspace with no engine-version declaration is not judged against
one, and the new catalog field appears only on keys that carry a closed value
set. Readers and writers of a chain that declares an engine version must run a
build that satisfies it.
