# 0.11.12

`0.11.11` added `--control-manifest-out` to `relocation-plan` and
`relocation-vacate` and did not add it to the command catalog. The flag worked;
the catalog did not know about it.

That gap matters more than a missing line of documentation. The catalog is this
engine's only authority on what exists — the MCP facade derives its tool schemas
from it, and this repository's own guidance says to enumerate capability from the
catalog and never from prose. A flag absent there is a flag no catalog-driven
caller can reach, and an operator who checked the catalog before an oversized
relocation would have concluded the escape hatch did not exist.

Both verbs now declare it.
