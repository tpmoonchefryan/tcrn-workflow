# TCRN Workflow 0.11.4

`0.11.4` is the INIT-020 storage-home and PG-test isolation release, cut on
top of `0.11.3` (`5649ce2`). It carries the engine-side protections needed by
the five-chain file→Postgres switch and the release evidence for STORY-191.

## The changes

- **Storage-home admission is explicit.** A file backend refuses mutating
  operations after a workspace declares `storage: "pg"`; the migration path is
  the only explicit migration admission and holds an archive-side lease while
  it snapshots, writes, seals, and removes the source tree.
- **Typed PG errors survive mapping.** Existing `StorageError` instances are
  returned unchanged instead of being swallowed by SQLSTATE translation.
- **PG tests are isolated and wired.** The suite applies its DDL and
  append-only trigger to a `chain_test_*` schema, never `chain_cross` or a
  production chain schema, and runs serially against the CI Postgres service.
- **Adapter parity is evidence-backed.** STORY-191 has a checked-in
  Codex/Claude equivalence matrix with shared reason-code and final-hop tests;
  host-specific surfaces are stated rather than counted as missing parity.

## Compatibility

- The CLI verb count stays 104 and the file backend remains unchanged for
  workspaces without a storage-home declaration.
- Existing PG migration and read paths keep their public command shapes.
- The release carries all five package manifests, `FRAMEWORK_VERSION`, and the
  P8 release constants on one version. Publishing/tag push remains an Owner
  gate and is intentionally outside this local task.
