# TCRN Workflow 1.0.1

A patch release carrying one fix. No event transform, `storageVersion` stays 1,
no verb added or removed, no successful command's reason code changed.

It exists as its own release rather than as a correction folded into `1.0.0`
because `v1.0.0`'s commit is red in CI, and a published release must point at a
lineage that was actually verified. The tag stays where it is; this is what
should be installed.

## The fix

`1.0.0` added a Markdown link gate after a published code of conduct spent a day
telling readers the authoritative text was at a path that did not exist. The gate
resolved a link target with `existsSync` and nothing else.

That made its verdict a function of what else was on the disk. A citation written
as `../../../../TCRN-Design-System/docs/...` resolved on a machine holding a
sibling checkout of that repository, and did not on a CI runner holding one
repository and nothing beside it. Five consecutive pushes were red while every
local run was green — and the gate meant to catch bad links was itself the thing
failing, in the direction nobody watches, because a local green is what gets
believed.

This platform's host-independence convention says a gate's verdict must not vary
with the host. This one did.

A link that climbs out of the repository is now refused on its shape, before any
filesystem question is asked, and reported as `escapes` rather than as a missing
file. The two have different remedies — correct the path, versus do not write a
filesystem path to another repository at all — so collapsing them would send a
reader to fix the wrong thing.

The gate shipped with no criteria of its own, which is how it carried a host
dependency past review. It has six now. One of them creates a real file *outside*
a fixture repository and asserts the link to it is still refused: the CI condition
asserted rather than hoped for, and the only criterion in the suite that can see
this class of defect on a developer machine.

## Upgrading

Replace the engine copy. No `recover`, no migration, nothing touched on any chain.
