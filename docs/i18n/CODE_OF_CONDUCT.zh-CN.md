# 行为准则

## 我们的承诺

我们承诺让每个人的参与都受到尊重、免于骚扰，无论其背景、身份、经历或个人特征如何。

## 期望的行为

保持建设性，在核验声明的同时假定善意，尊重隐私，并将批评聚焦于工作与决策。骚扰、威胁、人肉搜索（doxxing）、歧视以及不受欢迎的性关注都是不可接受的。

## 执行

请将行为方面的顾虑私下报告给仓库维护者。维护者可以移除内容、限制参与，或采取其他相称的措施。报告将被审慎处理，同时受法律与安全方面需要的约束。

本政策改编自 Contributor Covenant 2.1 的原则，未纳入任何外部联系方式。
