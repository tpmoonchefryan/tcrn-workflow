# 行動規範

## 私たちの誓約

私たちは、背景・アイデンティティ・経験・個人的特性を問わず、すべての人にとって参加が敬意あるものであり、ハラスメントのないものとなるよう誓います。

## 期待される振る舞い

建設的であること、主張を検証しつつ善意を前提とすること、プライバシーを尊重すること、そして批判を仕事と決定に向けること。ハラスメント、脅迫、ドキシング、差別、望まれない性的な言動は許容されません。

## 施行

行動に関する懸念は、リポジトリのメンテナへ非公開で報告してください。メンテナは、コンテンツの削除、参加の制限、またはその他の比例的な措置を取ることがあります。報告は裁量をもって取り扱われますが、法的および安全上の必要に従います。

本ポリシーは Contributor Covenant 2.1 の原則を翻案したものであり、外部の連絡先情報は組み込んでいません。
